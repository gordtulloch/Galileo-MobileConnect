## Galileo MobileConnect for Android 0.1.1 (testing)

Test build. Install the APK, then use the app against Galileo 0.9.08alpha or later with the MobileConnect plug-in 0.1.2 or later installed (Options > Plug-ins), or try the built-in demo with no equipment.

- **Sessions:** run the Master's saved sessions from the phone, and manage the queued jobs (pause, stop, reorder, remove).
- **Guiding:** Connect, Loop, Start and Stop in one row; a small guide-star picture; error numbers over the plot.
- **Focus:** autofocus now shows progress, the latest and lowest HFR, the V-curve and the result.
- **Imaging, Targets and Mount Control:** three-line capture panel with an exposure progress bar, one-row targets, and a smaller jog pad so the speed slider fits.
- **Star Atlas:** IC catalog added.

Android 8.0 or later. Android asks once to allow installs from your browser.
